# Alafia Cleaning

Marketing website for **Alafia Cleaning**, a residential and commercial cleaning company serving Mansfield, TX and surrounding communities.

Tagline: **Clean Home. Clear Mind. Peace of Mind.**

## Overview

A fast, fully responsive, mobile-optimized static website built with HTML and Tailwind CSS (via CDN). No build step is required. Open `index.html` in a browser or host the folder on any static host.

## Pages

- `index.html` - Home (hero and quote form, why choose us, services, process, before and after, areas served, recurring plans, reviews, FAQ, contact)
- `regular-house-cleaning.html`
- `deep-cleaning.html`
- `office-commercial-cleaning.html`
- `airbnb-rental-turnover.html`
- `move-in-move-out-cleaning.html`
- `carpet-cleaning.html`
